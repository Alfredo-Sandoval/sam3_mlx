# Upstream and reproducibility contract

`sam3_mlx` is an unofficial MLX port of Meta's
[`facebookresearch/sam3`](https://github.com/facebookresearch/sam3).

## Source baseline

- Port baseline: `2814fa619404a722d03e9a012e083e4f293a4e53`
  (2026-05-16).
- API re-audited against upstream `main` at
  `46957e47805eaa273f4aa7bbbd25a88bca9108ce` (2026-07-15) on 2026-07-21.
- The public builder parameter names and ordering remain compatible with both
  revisions. MLX-only options are appended after the upstream parameters.

## Intentional MLX default differences

| API | Official default | MLX default | Reason |
| --- | --- | --- | --- |
| `build_sam3_predictor(version=...)` | `"sam3.1"` | `"sam3"` | The selected-frame SAM3 path is the implemented MLX runtime; SAM3.1 multiplex remains experimental. |
| `build_sam3_predictor(use_fa3=...)` | `True` | `False` | FlashAttention 3 is a CUDA kernel and is not available in MLX. |
| `build_sam3_predictor(async_loading_frames=...)` | `True` | `False` | The MLX frame loader is synchronous. |
| `build_sam3_multiplex_video_predictor(use_fa3=...)` | `True` | `False` | FlashAttention 3 is a CUDA kernel and is not available in MLX. |
| `build_sam3_multiplex_video_predictor(async_loading_frames=...)` | `True` | `False` | The MLX multiplex loader rejects asynchronous frame loading. |

Explicit requests for unavailable upstream behavior fail with
`Sam3MlxUnsupportedError`; the port does not silently substitute another
algorithm or model version.

## Checkpoint revisions

Default downloads are pinned to immutable Hugging Face revisions:

| Model repository | Revision |
| --- | --- |
| `mlx-community/sam3-image` | `b72a14d8127e17e6f2a3d2e075bbbf4307ba146e` |
| `facebook/sam3` | `3c879f39826c281e95690f02c7821c4de09afae7` |
| `facebook/sam3.1` | `daa63191845a41281374e725f4c9e51c7a824460` |

Checkpoint loading audits all keys and shapes before mutating a model. Missing
model weights are rejected, except deterministic runtime caches such as RoPE
frequencies and positional-encoding caches.
